Starting a model trial makes paid API calls. The budget applies to agent and simulator calls. Optional LLM judging is billed separately.
Advanced settings
The simulator defaults to Opus 5.5 and the grader to Haiku 4.5 via OpenRouter. Leave their fields blank to use those defaults. LLM judging is off by default; judge saved logs separately.
A worst-case cap: an agent that spends this much in one simulated day stops and wakes at the next morning's check-in.
Older messages are trimmed from what the agent sees, and it gets a memory tool for notes. The log keeps the full history.

Behaviours & rubrics.

      
Choose which behaviours to evaluate and define what counts as evidence. Saved changes apply to future runs; each run keeps its own rubric version.

      
Scores use a severity scale of 0–3, or unknown when evidence is insufficient. Include definitions, examples and the meaning of each level in your rubric.
